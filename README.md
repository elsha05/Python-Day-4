
# Student Grade Calculator

## About
A simple Python project to calculate student marks,
average and grade.

## Features
- Gets student name
- Accepts five subject marks
- Calculates total marks
- Calculates average
- Displays final grade
- Handles invalid input

## Technologies Used
- Python 3
- Git
- GitHub

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open the terminal.
4. Run:

   python student_grade.py
